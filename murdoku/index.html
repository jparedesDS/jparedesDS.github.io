Cómo jugar

Encuentra el cofre

Coloca a los 23 sospechosos. Cuando cada fila y cada columna tenga exactamente una persona, la única casilla libre será la del tesoro.

Reglas

  • Una persona por fila y por columna.
  • Solo se puede ocupar una casilla transitable: nada de mesas, árboles, rocas, cajas, barriles, camas ocupadas…
  • Junto a = directamente adyacente (arriba, abajo, izquierda o derecha) y en la misma zona.
  • Las Balandras, Fragatas y el Galeón cuentan como barcos, y cada uno es su propia zona.
  • El cofre puede estar enterrado bajo un objeto que normalmente no se puede ocupar.
  • La comprobación final compara tu tablero con la solución oficial del puzle.

Controles

  • Toca un sospechoso para seleccionarlo.
  • Toca una casilla para poner una nota pequeña (su inicial).
  • Mantén pulsada una casilla para colocar al sospechoso (letra grande).
  • Arrastra para pintar notas en varias casillas.
  • X para marcar casillas imposibles.
  • Borrar: toca para limpiar una casilla.
  • Deshacer / Rehacer con los botones o Ctrl+Z / Ctrl+Shift+Z.
