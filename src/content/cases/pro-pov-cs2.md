## Problem

Professional Counter-Strike 2 matches are published as demos, but turning a demo into a watchable point-of-view video takes a chain of manual steps. Someone has to find the match, parse the demo, record the right player's perspective, cut it and publish it across several platforms. Done by hand, that pipeline does not scale to a regular publishing schedule.

## Approach

Pro POV CS2 automates the whole chain. The system discovers matches, parses the demo data, records each professional player's point of view, and prepares the result for publishing. Videos are then distributed through the channel's social accounts and collected on the project's own website. The work is treated as an end-to-end content pipeline rather than a set of one-off edits.

## Result

The Pro POV CS2 channel publishes professional player POV videos across YouTube, TikTok, Instagram and X, with the website acting as the hub. The source is private, so implementation details beyond this public description are not disclosed.
