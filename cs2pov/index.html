The cs2pov application

cs2pov is the channel's own tool. It runs on the channel owner's computer and uses the YouTube Data API (YouTube API Services) only on the channel owner's own account, to:

  • upload the recorded videos, their thumbnails and descriptions to the Pro POV CS2 channel;
  • add them to the channel's playlists;
  • read the view counts of the channel's own videos, to choose which matches to record next;
  • search public YouTube videos to estimate which players' POVs viewers look for.

It is not offered to other users and does not access anyone else's account. See the Privacy Policy and the Terms of Service.
