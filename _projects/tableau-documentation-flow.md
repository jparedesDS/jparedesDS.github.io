## Overview

A Tableau Public dashboard that tracks document inflow, processing and delivery across engineering projects. It provides a visual progress report of the documentation pipeline.

## Problem

Document-control work generates status data in several places. The dashboard brings that status into one visual view so progress can be monitored without reading through lists.

## Main features

- Visual progress report for documentation
- Monitors document inflow, processing and delivery across projects
- Published publicly on Tableau Public
