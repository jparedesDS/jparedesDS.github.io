## Overview

A data-wrangling and logistic-regression exercise on the Titanic dataset, centred on cleaning and analysing the data with pandas.

## Problem

The Titanic dataset needs cleaning and preparation before a classification model can be trained on it.

## Main features

- Complete cleaning and analysis of the dataset with pandas
- Logistic-regression classifier trained on the prepared data
- Accuracy of 0.8603 and ROC-AUC of 0.9185 reported in the repository

## Stack

- Python
- pandas
- Logistic regression
