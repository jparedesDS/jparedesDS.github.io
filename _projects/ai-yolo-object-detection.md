## Overview

An index repository for the YOLO models built for industrial inspection and video-game object detection. It groups the metallurgical models with the Counter-Strike 2, Valorant, Deadlock, Overwatch 2 and Fortnite detectors and points to their Hugging Face cards.

## Problem

The models are spread across several applications. This repository documents and links them from a single place.

## Main features

- Metallurgical models for fluorescent penetrant inspection and welding defects
- Counter-Strike 2 object-detection models based on YOLOv9 and YOLOv10
- Valorant, Deadlock, Overwatch 2 and Fortnite detectors
- Ultralytics inference snippet and links to every model card
- MIT license

## Stack

- YOLO through the Ultralytics library
- Python
