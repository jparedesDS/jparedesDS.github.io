# Astro portfolio

Personal portfolio of Jose Paredes, live at <https://jparedesds.github.io/>.

Static site built with [Astro](https://astro.build/) and hand-written CSS: no
Tailwind, no React and no framework runtime in the browser.

## Commands

| Command | What it does |
| --- | --- |
| `npm ci` | Install the exact dependencies from `package-lock.json`. |
| `npm run dev` | Start the dev server at <http://localhost:4321/>. |
| `npm run build` | Build the production site into `dist/`. |
| `npm run preview` | Serve the built `dist/` locally. |
| `npm test` | Build, then run the content tests in `test/content.test.mjs`. |
| `npx playwright test --config test/playwright.config.js` | Run the accessibility, responsive and SEO checks. |
| `npm run check` | Type-check the project with `astro check`. |

## Structure

```
src/
  components/     Header, Hero, WorkCard, WritingList, Footer, ...
  content/cases/  Five case studies as Markdown (Astro content collections)
  data/           Site metadata and the project list
  layouts/        BaseLayout (head, theme toggle, shell)
  pages/          /, /work/, /work/[slug]/ and sitemap.xml
  styles/         global.css and design tokens
public/           Static assets and legacy pages served as-is
test/             Node content tests and Playwright specs
```

## Deployment

Pushing to `main` runs the `Deploy portfolio` workflow
(`.github/workflows/deploy.yml`), which installs dependencies, builds `dist/`,
adds `dist/.nojekyll` and publishes it to the `gh-pages` branch. GitHub Pages
serves that branch, so `dist/` fully replaces the previous output on every
deploy.

## URLs kept on purpose

- `/`, `/work/` and `/work/<slug>/` are generated by Astro.
- `/cleanyourmail/`, `/cs2pov/`, `/murdoku/` and `/propovcs2/` are legacy
  subsites copied under `public/` and served unchanged.
- `/projects/`, `/projects/ai-vision/`, `/projects/data-automation/`,
  `/projects/esports/` and `/projects/products/` are static redirect pages
  under `public/projects/` that point at the new `/work/` routes.
- `/resume.pdf`, `/profile.jpg`, `/robots.txt` and the other files in
  `public/` are preserved.

The blog lives at `/blog/` and is a separate Hugo project site; it is not built
or deployed from this repository.
