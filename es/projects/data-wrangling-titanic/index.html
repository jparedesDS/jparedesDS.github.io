Datos y Automatización

Preparación de datos del Titanic

Limpieza y análisis completos del conjunto de datos del Titanic con pandas y un modelo de regresión logística.

  • Código

Resumen

Un ejercicio de preparación de datos y regresión logística sobre el conjunto de datos del Titanic, centrado en limpiar y analizar los datos con pandas.

Problema

El conjunto de datos del Titanic necesita limpieza y preparación antes de poder entrenar un modelo de clasificación con él.

Funcionalidades principales

  • Limpieza y análisis completos del conjunto de datos con pandas
  • Clasificador de regresión logística entrenado con los datos preparados
  • Precisión de 0,8603 y ROC-AUC de 0,9185 reportadas en el repositorio
